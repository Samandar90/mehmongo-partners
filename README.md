# MehmonGo — страница для отелей

Партнёрская страница: что получает отель, сколько это в деньгах и как проверить расчёты.

Живая версия: https://samandar90.github.io/mehmongo-partners/

## Что где менять

Всё в одном файле `index.html`, без сборки и зависимостей.

| Что | Где |
| --- | --- |
| Ставки за заявку | `RATES` в теге `<script>` внизу файла |
| Уровни и надбавки | `TIERS` там же |
| Примеры в таблицах | разметка секции `#skolko` — правьте вместе со ставками |
| Телефон | три места: верхняя панель, блок «Поговорим», и `href="tel:"` |

После правки ставок пересчитайте примеры в обеих таблицах, иначе цифры в калькуляторе
и в таблицах разойдутся.
